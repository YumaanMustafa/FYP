# Stitch3D Platform - Modular Monorepo

Welcome to the Stitch3D platform repository. The codebase is organized into two primary logical directories:

* **`frontend/`**: The complete Next.js user interface, 3D jacket customizer (Fabric.js engine), customer, vendor, supplier, and admin portals.
* **`backend/`**: The REST API endpoints, database connection pools, JWT authentication layer, email services, and database schema scripts.

## Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
```

## Backend Services

Refer to `backend/README.md` for database schema setups, environment configurations, and API route specifications.
